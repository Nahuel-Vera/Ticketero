# Ticketero 🤖


## Instalación previa:

```bash
pip install -r requirements.txt
``` 

---

De momento se utiliza desde `"uvicorn"`
con el comando:
```bash
uvicorn Back.main:app --reload
```

esto levanta en la url con `fastAPI`:
"http://127.0.0.1:8000/test"


---

### INFO adicional:

Significado:
- Back → carpeta
- main → archivo main.py
- app → instancia app = FastAPI()
